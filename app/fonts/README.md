# Fonts

Latin subsets (Google Fonts' `latin` range) taken from the reference prototype. Both cover every French character the game uses (PRD GAME-14), including é è ê ë à â ç î ï ô û ù œ É À Ç « » and the no-break space. Neither has ✓, so the UI draws it as SVG.
